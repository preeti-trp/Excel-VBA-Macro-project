<h1>Sales Persons Ranking Dashboard</h1>


<h2>Description</h2>
Project consists of an interactive dashboard built in excel using VBA and Macro that shows the sales employees who are performing highest and lowest respectively in various cities. 
<br />


<h2>Languages and Utilities Used</h2>

- <b>Visual Basic Applications Macro</b> 
- <b>Excel</b>

<h2>Environments Used </h2>

- <b>Windows 10</b> (21H2)
